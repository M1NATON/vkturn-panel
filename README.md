# VK TURN Panel + Bot

Простая панель управления и Telegram-бот для раздачи VPN-доступов через VK Calls и WireGuard.

Проект основан на ядре [@cacggghp/vk-turn-proxy](https://github.com/cacggghp/vk-turn-proxy).

**Основной функционал:**
- 📱 Генерация iOS-приложением ссылок вида `vkturnproxy://`
- 🔐 Управление VPN-пирами (WireGuard Peer'ы)
- 🤖 Автоматизация через Telegram-бота
- 🔄 Автоматическое создание ВК-звонков через VK API
- 📊 Статистика пользователей и админ-панель

## Быстрый старт

### Требования
- **ОС**: Linux (Ubuntu/Debian рекомендуется)
- **Права**: root или sudo
- **Зависимости**: WireGuard, Python 3, Git, vk-turn-proxy
- **Сеть**: Открытый порт 56000 (WireGuard) и 8808 (панель)

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/M1NATON/vkturn-panel.git /apps/vkturn-panel
cd /apps/vkturn-panel
```

### Шаг 2: Выбери способ установки

Выполни **один** из трёх скриптов (от root):

#### Вариант A: Чистый VPS (всё сразу)
Если на сервере ничего нет:

```bash
bash install-full.sh
```

**Устанавливает:** WireGuard + vk-turn-proxy + панель + бот

#### Вариант B: WireGuard и vk-turn-proxy уже есть
Если сервер частично готов:

```bash
bash install.sh
```

**Устанавливает:** только панель и бот

#### Вариант C: Нужна только серверная часть
Если уже есть панель/бот:

```bash
bash install-server.sh
```

**Устанавливает:** WireGuard + vk-turn-proxy

> 💡 **Важно:** Все скрипты идемпотентны — повторный запуск не сотрёт существующие конфиги.

### Шаг 3: Настройка

Отредактируй конфиг:

```bash
nano /opt/vkturn/config.json
```

**Обязательные поля:**

| Поле | Что это | Где взять |
|------|---------|----------|
| `peer_address` | IP:порт сервера (для клиентов) | Публичный IP сервера + порт 56000 |
| `vk_links` | Ссылки на ВК-звонки | Мобильное приложение → «Get VK call URL» |
| `panel_password` | Пароль для входа в панель | Придумай сам |
| `bot_token` | Токен Telegram-бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `admin_ids` | Telegram ID админа | [@userinfobot](https://t.me/userinfobot) |

**Опциональные поля:**

| Поле | Что это |
|------|---------|
| `server_public_key` | Подставляется автоматически |
| `testflight_url` | Ссылка на iOS TestFlight (уже заполнена) |
| `vk_access_token` | Токен для автосоздания звонков |

### Шаг 4: Запуск

```bash
# Запусти панель и бот
systemctl enable --now vkturn-panel
systemctl enable --now vkturn-bot

# Если используешь ufw
ufw allow 8808
ufw allow 56000
```

**Панель доступна по адресу:** `http://ТВ_IP_СЕРВЕРА:8808`

## Использование

### 📋 Панель управления

```
http://ТВ_IP_СЕРВЕРА:8808
```

1. Введи пароль (из конфига)
2. Нажми **«+ Добавить»**
3. Получишь QR-код и ссылку для передачи пользователю

### 🤖 Telegram-бот

**Для пользователей** — отправь им ссылку на бота:
```
t.me/твой_бот_username
```

Команды в боте:
- `/start` — главное меню
- **Мой доступ** — получить ссылку + QR
- **Инструкция** — как настроить
- **Мой статус** — проверить активность

**Для админа** — команды:
- `/admin` или кнопка в меню
- `/users` — список всех пользователей
- `/revoke 10.8.0.5` — отключить конкретного пользователя
- Отправь боту ссылку на ВК-звонок → добавится в пул

### ⚙️ Администрирование

В панели есть раздел **Админка** (или `/admin` в боте):
- Просмотр всех пользователей
- Управление пирами
- Статистика использования
- Настройка автосоздания звонков

## Автоматическое создание ВК-звонков

Если устанешь вручную копировать ссылки — включи автоматику. Панель сама будет создавать свежие звонки через VK API.

**Преимущества:**
- Звонки создаются автоматически
- Живут бесконечно долго (в отличие от ручных)
- Всегда первая рабочая ссылка в пуле

### Как включить (30 сек с iPhone)

1. **В Safari** войди в ВК под отдельным аккаунтом (рекомендуется "burner"):
   ```
   https://m.vk.com
   ```

2. **Получи токен** — откупи эту ссылку:
   ```
   https://oauth.vk.ru/authorize?client_id=6287487&scope=calls&response_type=token
   ```
   Нажми «Continue as» → система перенаправит

3. **Скопируй токен** из адресной строки:
   ```
   https://oauth.vk.ru/#access_token=ВОТ_ЭТО_ТОКЕН&...
   ```

4. **Вставь в панель:**
   - Открой панель (`http://IP:8808`)
   - Раздел **Настройки**
   - Вставь токен → **Сохранить**

✅ **Готово!** При каждой выдаче доступа система создаст свежий звонок.

> 🔔 **Важно:** Токен живёт ~1 год. Если автосоздание перестанет работать — повтори шаги выше.

## Частые вопросы

**Q: Как узнать публичный IP сервера?**
```bash
curl -s https://api.ipify.org
```

**Q: Какой порт нужен для WireGuard?**
По умолчанию **56000** (можно изменить в конфиге WireGuard).

**Q: Можно ли использовать на VPS?**
Да! Все три скрипта установки заточены под VPS.

**Q: Что если пользователь потеряет доступ?**
- Через панель: отключи и заново добавь пира
- Через бота: админ отправляет новую ссылку

**Q: WireGuard работает, но панель не видит конфиг?**
```bash
# Проверь права доступа
ls -la /etc/wireguard/wg0.conf
# Должно быть: -rw------- root root
```
